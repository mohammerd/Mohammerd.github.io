# Muhammad Zakari — Personal Website

This repository contains the source for [mohammerd.github.io](https://mohammerd.github.io), the personal website of Muhammad Zakari.

The site is built with Next.js, React, TypeScript, and Tailwind CSS, and is published as a static website using GitHub Pages.

## What the site contains

- An introduction and background.
- Research and project pages for AgroGuardAI, Hypervisor-Zero, and AgroMind.
- A Writing section for future essays, research notes, and project updates.
- Contact links for GitHub, X, Instagram, LinkedIn, and email.

## Development

The project uses Node.js and npm.

```bash
npm ci
npm run dev
```

Open http://localhost:3000 to preview the site.

Useful checks:

```bash
npm test
npm run lint
npm run type-check
npm run build
```

## Deployment

The site is configured for GitHub Pages at https://mohammerd.github.io/.
